# 📜 Normativa Curricular de Illes Balears (Estándar OKF)

Este directorio aloja las disposiciones normativas de ordenación y currículo para las enseñanzas no universitarias en **Illes Balears**.

## Decretos Curriculares de Etapa:
1. **Educación Infantil:** Decreto 30/2022, de 1 de agosto (BOIB n.º 102, 06/08/2022)
2. **Educación Primaria:** Decreto 31/2022, de 1 de agosto (BOIB n.º 102, 06/08/2022)
3. **Educación Secundaria Obligatoria (ESO):** Decreto 32/2022, de 1 de agosto (BOIB n.º 102, 06/08/2022)
4. **Bachillerato:** Decreto 33/2022, de 1 de agosto (BOIB n.º 102, 06/08/2022)

*Publicadas en BOIB (Butlletí Oficial de les Illes Balears). Estructuradas con metadatos YAML compatibles con el esquema oficial `schema/norm_schema.json` y el repositorio hermano [open-lex-edu](https://github.com/nmarafo/open-lex-edu).*
