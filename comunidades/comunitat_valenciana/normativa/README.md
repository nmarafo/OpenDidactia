# 📜 Normativa Curricular de Comunitat Valenciana (Estándar OKF)

Este directorio aloja las disposiciones normativas de ordenación y currículo para las enseñanzas no universitarias en **Comunitat Valenciana**.

## Decretos Curriculares de Etapa:
1. **Educación Infantil:** Decret 100/2022, de 29 de juliol (DOGV n.º 9399, 05/08/2022)
2. **Educación Primaria:** Decret 106/2022, de 5 d'agost (DOGV n.º 9403, 11/08/2022)
3. **Educación Secundaria Obligatoria (ESO):** Decret 107/2022, de 5 d'agost (DOGV n.º 9404, 12/08/2022)
4. **Bachillerato:** Decret 108/2022, de 5 d'agost (DOGV n.º 9405, 12/08/2022)

*Publicadas en DOGV (Diari Oficial de la Generalitat Valenciana). Estructuradas con metadatos YAML compatibles con el esquema oficial `schema/norm_schema.json` y el repositorio hermano [open-lex-edu](https://github.com/nmarafo/open-lex-edu).*
