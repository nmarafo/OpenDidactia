# 📜 Normativa Curricular de Comunidad Foral de Navarra (Estándar OKF)

Este directorio aloja las disposiciones normativas de ordenación y currículo para las enseñanzas no universitarias en **Comunidad Foral de Navarra**.

## Decretos Curriculares de Etapa:
1. **Educación Infantil:** Decreto Foral 61/2022, de 1 de junio (BON n.º 125, 23/06/2022)
2. **Educación Primaria:** Decreto Foral 67/2022, de 22 de junio (BON n.º 129, 29/06/2022)
3. **Educación Secundaria Obligatoria (ESO):** Decreto Foral 71/2022, de 29 de junio (BON n.º 137, 11/07/2022)
4. **Bachillerato:** Decreto Foral 72/2022, de 29 de junio (BON n.º 137, 11/07/2022)

*Publicadas en BON (Boletín Oficial de Navarra). Estructuradas con metadatos YAML compatibles con el esquema oficial `schema/norm_schema.json` y el repositorio hermano [open-lex-edu](https://github.com/nmarafo/open-lex-edu).*
