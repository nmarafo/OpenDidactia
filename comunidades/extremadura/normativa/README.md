# 📜 Marco Normativo y Currículos Oficiales: Extremadura (Estándar OKF)

Este directorio aloja las transcripciones íntegras y disposiciones oficiales de ordenación académica, currículo y evaluación para las enseñanzas no universitarias en **Extremadura**, estructuradas bajo el estándar **Open Knowledge Framework (OKF)** y sincronizadas con el repositorio jurídico canónico [**nmarafo/open-lex-edu**](https://github.com/nmarafo/open-lex-edu).

Cada documento incluye metadatos YAML enriquecidos (`id`, `titulo`, `boletin`, `clasificacion`, `relaciones`) y el articulado completo junto a sus anexos de **competencias específicas, criterios de evaluación y saberes básicos autonómicos**.
