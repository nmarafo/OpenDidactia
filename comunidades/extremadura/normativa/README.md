# 📜 Normativa Curricular de Extremadura (Estándar OKF)

Este directorio aloja las disposiciones normativas de ordenación y currículo para las enseñanzas no universitarias en **Extremadura**.

## Decretos Curriculares de Etapa:
1. **Educación Infantil:** Decreto 98/2022, de 20 de julio (DOE n.º 142, 25/07/2022)
2. **Educación Primaria:** Decreto 105/2022, de 3 de agosto (DOE n.º 151, 05/08/2022)
3. **Educación Secundaria Obligatoria (ESO):** Decreto 110/2022, de 22 de agosto (DOE n.º 164, 25/08/2022)
4. **Bachillerato:** Decreto 109/2022, de 22 de agosto (DOE n.º 164, 25/08/2022)

*Publicadas en DOE (Diario Oficial de Extremadura). Estructuradas con metadatos YAML compatibles con el esquema oficial `schema/norm_schema.json` y el repositorio hermano [open-lex-edu](https://github.com/nmarafo/open-lex-edu).*
