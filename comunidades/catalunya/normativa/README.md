# 📜 Normativa Curricular de Catalunya (Estándar OKF)

Este directorio aloja las disposiciones normativas de ordenación y currículo para las enseñanzas no universitarias en **Catalunya**.

## Decretos Curriculares de Etapa:
1. **Educación Infantil:** Decret 21/2023, de 7 de febrer (DOGC n.º 8851, 09/02/2023)
2. **Educación Primaria:** Decret 175/2022, de 27 de setembre (Educació Bàsica - DOGC n.º 8762, 29/09/2022)
3. **Educación Secundaria Obligatoria (ESO):** Decret 175/2022, de 27 de setembre (Educació Bàsica - DOGC n.º 8762, 29/09/2022)
4. **Bachillerato:** Decret 171/2022, de 20 de setembre (Batxillerat - DOGC n.º 8758, 22/09/2022)

*Publicadas en DOGC (Diari Oficial de la Generalitat de Catalunya). Estructuradas con metadatos YAML compatibles con el esquema oficial `schema/norm_schema.json` y el repositorio hermano [open-lex-edu](https://github.com/nmarafo/open-lex-edu).*
