# 📜 Normativa Curricular de Cantabria (Estándar OKF)

Este directorio aloja las disposiciones normativas de ordenación y currículo para las enseñanzas no universitarias en **Cantabria**.

## Decretos Curriculares de Etapa:
1. **Educación Infantil:** Decreto 66/2022, de 7 de julio (BOC n.º 135, 13/07/2022)
2. **Educación Primaria:** Decreto 67/2022, de 7 de julio (BOC n.º 135, 13/07/2022)
3. **Educación Secundaria Obligatoria (ESO):** Decreto 74/2022, de 21 de julio (BOC n.º 144, 26/07/2022)
4. **Bachillerato:** Decreto 75/2022, de 21 de julio (BOC n.º 144, 26/07/2022)

*Publicadas en BOC (Boletín Oficial de Cantabria). Estructuradas con metadatos YAML compatibles con el esquema oficial `schema/norm_schema.json` y el repositorio hermano [open-lex-edu](https://github.com/nmarafo/open-lex-edu).*
